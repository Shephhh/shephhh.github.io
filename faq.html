PLAYER SUPPORT

FREQUENTLY ASKED QUESTIONS

Is ELEMENTAL RUN free to play?

Yes. The browser version can be started from the home page without creating an account. The Steam page is linked separately for players who prefer the desktop release.

Which browsers and devices are supported?

Use a current version of Chrome, Edge, Firefox, or Safari with WebGL enabled. Desktop uses keyboard and mouse controls. Phones and tablets use touch controls and receive a layout suited to their screen orientation.

Why does the first load take longer than a replay?

The first visit prepares the 3D world, shaders, music, and selected visual models. Later visits can reuse browser-cached files. A slow or unstable connection can still delay large assets; wait for the loading indicator to finish before starting a run.

How can I improve performance?

Open Settings and select Performance or Balanced. Close other demanding browser tabs, keep hardware acceleration enabled, and avoid battery-saving browser modes. The game can also lower rendering work when it detects sustained frame-time pressure.

Where are my score, gold, and upgrades saved?

Browser progress is stored locally on the device and browser you use. Clearing site data or using private browsing can remove that local save. Steam uses its own platform services when available.

Do ads grant rewards automatically?

No. A reward is only granted after a supported rewarded-ad provider reports a completed view. If no ad is available, the game keeps normal play available and does not award an unearned bonus.

How do I report a bug?

Please use the official ELEMENTAL RUN Steam page to reach the publisher. Include your browser/device, map, and a short description of what happened.
