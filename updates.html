ELEMENTAL RUN v1.3

Browser-first performance

The browser build adapts resolution, visual effects, shadow work, and route visibility to maintain a responsive run on a wide range of devices. Graphics settings remain available for players who want a different balance.

Desktop and mobile input

Desktop supports keyboard and mouse play. Mobile players receive touch controls and a layout tuned for small screens. The game also detects device characteristics to avoid loading unnecessary high-cost models.

What is being improved

Each update focuses on game readability: cleaner obstacle spawning, reliable first-person hands, visible vehicles and trains, and predictable loading behavior. Feedback from real runs guides future changes.
